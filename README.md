## Funcionamento das aulas

- **Quinta-feira:** aulas teórico-práticas acompanhadas pelo professor.
- **Terça-feira:** aulas laboratoriais em trabalho autónomo, destinadas à resolução de exercícios e à execução de laboratórios em Python.

## Avaliação

| Componente | Peso |
| --- | --- |
| Exame | 50% |
| Projeto | 40% |
| Laboratórios | 10% |

Nota final = 0,50 × Exame + 0,40 × Projeto + 0,10 × Laboratórios.

## Entrega dos laboratórios

A nota dos laboratórios é a média das classificações dos laboratórios entregues.

Enviar o trabalho para **antonio.leonardo.goncalves@marinha.pt**, até às **23h00 de sexta-feira da semana seguinte àquela em que a matéria foi lecionada**.

## Utilização dos laboratórios no Google Colab

Os links «Notebook (IPYNB)» apontam para os ficheiros locais incluídos no ZIP. Para os utilizar no Google Colab, abrir o Colab, iniciar sessão numa conta Google e carregar o ficheiro `.ipynb` pretendido. Guardar uma cópia no Drive, executar as células por ordem e seguir o enunciado. Guardar o trabalho e descarregar o notebook para entrega. Os ficheiros produzidos durante a execução ficam no ambiente temporário do Colab e devem ser descarregados se forem necessários.
